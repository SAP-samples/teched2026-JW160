# Joule 101: Prompting, agents, skills, and deep reasoning — hands on

## Description

This repository contains the hands-on material for the SAP TechEd 2026 session **Joule 101: Prompting, agents, skills, and deep reasoning — hands on**.

Across 10 exercises you'll use Joule, SAP's AI assistant, to retrieve live data from SAP S/4HANA and SAP SuccessFactors, generate business documents, analyse uploaded files, combine data across systems, and extend Joule's capabilities with a custom skill. No transaction codes. No menus. Just conversation.

## Overview

Joule translates natural-language questions into real-time actions across your SAP landscape. This session works through what that looks like in practice, from a first conversation to a full end-to-end workflow spanning ERP, HR, the web, and a custom-built capability.

By the end of the session, you will have:
- Retrieved live procurement and HR data through conversation
- Combined data from S/4HANA and SuccessFactors in a single answer
- Generated Word, PDF, and HTML outputs from live SAP data
- Used web search to compare your company's KPIs against industry figures
- Explored data relationships through the SAP Knowledge Graph
- Installed and tested a custom Joule skill


## Requirements

- Access to an SAP Fiori Launchpad with Joule enabled (provided by your instructor)
- Login credentials for this session's demo environment
- A modern browser (Chrome or Edge recommended)
- No SAP background required
